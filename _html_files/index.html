A practical guide to troubleshooting Cisco ACI

Introduction to ACI Troubleshooting

Cisco Application Centric Infrastructure (ACI) is a powerful Software-Defined Networking (SDN) solution, but like any complex system, it requires a systematic approach to troubleshooting. Understanding the core ACI components, such as APIC, Spine, Leaf, EPGs, and Contracts, is the first step towards effective diagnostics.

This resource is intended for network engineers working with ACI and provides information on common problems, diagnostic methods, and useful tools. We will cover both fabric-level issues and complexities related to endpoint connectivity and policy enforcement.

Common Troubleshooting Scenarios

When working with ACI, engineers often encounter a set of typical problems. These include:

  • Fabric Discovery Issues.
  • Lack of connectivity between Endpoints within the same or different EPGs.
  • Incorrect application of Contracts and Filters.
  • Problems with L4-L7 service integration.
  • Difficulties connecting to external networks (L3Out).
  • APIC configuration errors or policy faults.

Each of these problems has its own diagnostic techniques, involving checking object states in the GUI/CLI/API, analyzing logs, and using built-in ACI tools like the Endpoint Tracker or the Troubleshooting Wizard.
